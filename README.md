## What this is

One sentence, at most 240 characters, to convince a friend who has never coded to let an AI agent build their first app idea on make.fun:

> You describe your app idea in one sentence, an AI agent builds it on make.fun, and if it places you get paid in USDC - no coding needed.

## How it works

`main.py` (Python 3.13, no network, deterministic) writes the pitch to `/output/entry.txt`.

```bash
python3 main.py
```
